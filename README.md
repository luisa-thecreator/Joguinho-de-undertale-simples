# Joguinho-de-undertale-simples

Jogo simples inspirado em Undertale, feito com HTML, CSS e JavaScript.

## Objetivo do Jogo

Neste jogo, você controla um personagem, a alma da Perseverança, que precisa evitar inimigos (os ossos) e evitá-los o máximo que conseguir. A mecânica do jogo é simples e divertida, com movimentos, colisões e tela de derrota (game over).

## Tecnologias Usadas

HTML: Estrutura do jogo (telas, menus, etc.)
CSS: Estilização das páginas e animações
JavaScript: Lógica do jogo (movimentos, colisões, derrota)


## Como Rodar o Jogo

1. Clone o repositório:

   ```bash
   git clone https://github.com/luisa-thecreator/Joguinho-de-undertale-simples.git
   ```

2. Abra o arquivo `indexmenu.html` no seu navegador para jogar!

## 💡 Funcionalidades

* Movimentação do personagem usando a tecla 'space/espaço' do teclado.
* Colisões com inimigos.
* Tela de derrota.

## Responsividade

O jogo ainda será adaptado para celulares, tablets e outros aparelhos móveis.
